# Multinational Finance Sample Data Index

Pattern:
`wwwroot/sample-data/{Continent}/{InstitutionType}/{InstitutionName}/{fileName}`

## Continent Roots

- Africa
- Asia
- Europe
- World

## Coverage Notes

- World bundles include partner institutions, MDB programs, co-financing, and AgriConnect samples.
- Africa bundles include AfDB, project pipeline, and sovereign risk samples.
- Europe bundles include EIB-focused institution and program data.
- Asia bundles include a reusable development finance institution sample.
- Sample data is JSON-backed and designed for the existing mock services.
